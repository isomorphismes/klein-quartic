## Hyperbolic `(2,3,7)` covering-space companion

A separate [exact finite quotient and Poincaré-disk reflection experiment](https://github.com/isomorphismes/Conway/tree/main/hyperbolic237) verifies the Klein quartic's `{7,3}` map (24 heptagons, 84 edges, 56 vertices, genus three). Read [the covering-space and finite-quotient notes](notes/triangle-237-cover.md) for the connection to this VTK/papercraft representation and the remaining geometric correspondence work. This work does not modify Hutton's original renderer.
